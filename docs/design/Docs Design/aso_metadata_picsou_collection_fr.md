Picsou Collection est l'outil indispensable pour tout collectionneur Disney souhaitant gérer sa bibliothèque avec précision et rapidité. Fini les achats en double et les doutes devant un carton de magazines !

### 🚀 Vos outils pour le terrain
*   **Identification Instantanée** : Scannez le code-barres ou utilisez la reconnaissance visuelle (OCR) pour identifier un numéro en quelques secondes.
*   **Statut en un coup d'œil** : L'application vous indique immédiatement si vous possédez déjà cette édition précise.
*   **Mode Offline First** : Conçue pour fonctionner partout, même sans connexion internet au fond d'une brocante.

### 📚 Maîtrisez votre collection
*   **Base de données locale** : Vos données vous appartiennent. Stockage 100% local, sans serveur ni compte obligatoire.
*   **Gestion des exemplaires** : Enregistrez l'état de vos magazines, ajoutez des notes personnelles et gérez vos multiples.
*   **Filtres avancés** : Recherchez par publication (Picsou Magazine, Super Picsou Géant, Mickey Parade...), par année ou par numéro.

### 🔐 Souveraineté et Sauvegarde
*   **Export/Import JSON** : Sauvegardez votre collection dans un fichier portable. Changez de téléphone sans perdre une seule donnée.
*   **Confidentialité totale** : Aucune photo n'est stockée, aucune donnée personnelle n'est collectée.
